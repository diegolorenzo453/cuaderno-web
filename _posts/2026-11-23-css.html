El diseño de la portada parte de una cuadrícula. En una pantalla amplia, las tres entradas se leen en paralelo. En una pantalla estrecha, las tarjetas se apilan para que el texto conserve espacio y el usuario pueda desplazarse hacia abajo.

La hoja de estilos comparte los colores, los márgenes y la tipografía entre todas las páginas. Una consulta de medios cambia la cuadrícula cuando el ancho disponible baja de 760 píxeles.

Ejemplo

@media (max-width: 760px) {
  .grid {
    grid-template-columns: 1fr;
  }
}
